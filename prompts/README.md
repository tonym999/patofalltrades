# Prompts Directory

This directory contains templates used by the AI workflow.

## Files
- [github-workflow.md](./github-workflow.md): End-to-end ticket-to-PR automation steps, using the `gh` CLI.
- [test-creation.md](./test-creation.md): Patterns and templates for Playwright tests.
- [commit-standards.md](./commit-standards.md): Conventional commits guidance.

## Usage
- Reference these templates when executing tickets with an AI coding agent.
- [`AGENTS.md`](../AGENTS.md) stays authoritative; these templates hold command-level detail only.
- Repo skills live in [`.claude/skills/`](../.claude/skills/) — prefer linking to a skill over duplicating its guidance here.
- Customize as needed per feature, keeping consistency across projects.
